# **Data Science Skills**

## Posting 1: Data Processing User Support Technician

### **Required**
- Employee Training
- Software/Hardware Installation
- Managing Employee Training Classes

### **Preferred**
- Technical Writing
- Data Processing Experience

## Posting 2: Corporate Advanced Analyst

### **Required**
- Data Processing Documentation Writing
- Project Coordination

### **Preferred**
- OLAP tools
- SQL, R, or SAS/SPSS
- Research experience

## Skills that appear in **BOTH**
- Communication
- Microsoft Office
- Problem Solving
- Data Management
- Troubleshooting
- Data Modeling

I was surprised by how different the skills in each of the jobs are while still having the core of what data science is. It gives me a good idea for a lot of skills I should work on as I go through college in this major.
